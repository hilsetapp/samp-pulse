# Изменения

## [0.1.2] - 2026-10-17

### Изменено
- Данные теперь лежат рядом с сайтом, в папке data: тот же домен, что у страницы, поэтому если сайт открылся, цифры тоже придут
- Живой список серверов и сохранённый снимок грузятся одновременно: что ответит первым, то и на экране
- Сборщик после каждого снимка публикует сайт вместе со свежими данными
- Список файлов истории пишется в meta.json: сайт больше не стучится в файлы, которых нет
- Если данных нет совсем, подпись честно говорит «данных нет, жми Обновить», а не «обновлено»

## [0.1.1] - 2026-10-17

### Исправлено
- Сайт больше не виснет пустым, если список серверов отвечает медленно: у всех запросов появился тайм-аут
- Если живой список не ответил за 8 секунд, сайт показывает последний сохранённый снимок, а живые цифры подставляет фоном
- Подпись сверху честно говорит, что происходит: «загружаю список», «сервер не отвечает», сколько минут назад обновлено
- Сборщик истории записывается в ветку data без падений на пустом репозитории
- Запасное зеркало данных заменено на такое, которое не кэширует ветку на сутки

## [0.1.0] - 2026-10-16

### Добавлено
- Живой онлайн из открытого списка open.mp: тянется прямо из браузера, всегда свежие цифры
- Топ-5 самых людных серверов, график онлайна за сутки, отдельная линия русскоязычного сегмента
- История по серверам: средний онлайн и пик по часам, искра в строке списка
- Поиск, фильтры (язык, режим, версия, только живые, без пароля), сортировки
- Избранное и ссылка на сервер вида #s=IP:порт
- Кнопка «Играть»: открывает клиент по протоколу samp://, рядом копирование IP
- Сбор истории: GitHub Action каждые 15 минут пишет в ветку data
- Мобильная вёрстка: таблица превращается в карточки
